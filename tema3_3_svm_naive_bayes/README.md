# Tema 3.3: Máquinas de Vectores de Soporte (SVM) y Naive Bayes

## Concepto Teórico
* **SVM (Support Vector Machines):** Busca trazar una 'frontera o calle de separación' óptima entre dos grupos de datos. Si los datos no se pueden separar con una línea recta, utiliza un 'truco matemático' (Kernel) para proyectarlos a un espacio de mayor dimensión donde sí sean separables.
* **Naive Bayes:** Utiliza la probabilidad bayesiana asumiendo que todas las variables son independientes entre sí; resulta ideal para clasificar texto o correos como Spam / No Spam por su alta velocidad de ejecución.

## Interpretación de Resultados
SVM logra delimitar fronteras complejas y curvas gracias al Kernel RBF. Por su parte, Naive Bayes —aunque asume la 'ingenuidad' de que las variables no se relacionan entre sí— alcanza un rendimiento competitivo en una fracción del tiempo de cómputo.
